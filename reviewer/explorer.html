    Hash operations

    Keccak-256 commitment

    Computed in this browser. Each leaf is its index encoded as an 8-byte little-endian integer. Internal nodes hash the ordered pair of child digests. An absent child is an identity operation and costs no hash.

    Checks on browser-computed states

    Checks evaluate the generated structures and compare their roots and hash counts with Clojure reference values where available. These finite checks do not constitute formal proofs.

    Reproduction and scope

    From the repository root, run clojure -M reviewer/export.clj. The generator produces this standalone docs/index.html, including Clojure reference fixtures. See reviewer/README.md for validation and anonymous Pages setup.

    The browser implements the append schedule and reuses range/belt hashes when their operands are unchanged. Structural counts exclude the one leaf hash per append, layout, proof generation, and verification. They measure hash work, not browser execution time. Previous states are retained for navigation.

    Clojure reference checks cover all 64 initial roots and paths, hash counts through 4,096 appends, selected larger roots, and recency samples 1–16. Source test results above are recorded during export, not executed in this browser. Lemma numbers may differ between paper revisions.

    This page is self-contained and makes no network requests.
